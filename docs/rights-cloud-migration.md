## 目标与边界

- 权益唯一正式数据源：腾讯云 MySQL `price_monitor.ledger`。不向 146 PostgreSQL 同步。
- 权益 MCP 与 MySQL 同机，服务仅监听 `127.0.0.1:8812`；本地通过 SSH 转发 `127.0.0.1:18812` 接入。3306 保持仅本机监听。以后有 HTTPS 域名时可迁移传输层。
- 政策、新车、口碑继续使用 146。保留权益插件 ID 和已有七个工具名称。
- 不修改采集任务，不修改数据库表结构，不删除旧服务；旧库只作暂存回退对象，不自动回退读取旧数据。
- 页面速览、插件卡片、明细、查询、导出必须调用相同权益 MCP 配置，浏览器不持有 Token。

## 已完成的本地准备

插件目录支持每个插件的独立 URL 和独立凭据。当前配置为：

```
MARKET_MCP_RIGHTS_URL=http://127.0.0.1:18812/mcp
MARKET_MCP_RIGHTS_API_TOKEN=<权益服务专用 Token>
```

这是完整 MCP 地址，不再拼接 146 的 `/mcp/rights`。设置独立 URL 后缺少独立 Token 会报告配置错误，不会把 146 Token 发给云端。未设置独立 URL 时保持既有配置，不改变当前服务。

## 运行和维护

智能体正常启动后，权益查询会自动启动本地 SSH 通道，无需在 Codex 中执行 MCP。通道连接断开时尝试重连；鉴权失败停止，不输出凭据。首次查询可能需要数秒。

本地通道独立环境：`runtime/rights-ssh-env`，基于项目 Python。新电脑不可直接复制 Windows 虚拟环境，应在项目根目录运行：

```powershell
python -m venv runtime/rights-ssh-env
runtime/rights-ssh-env/Scripts/python.exe -m pip install -i https://mirrors.aliyun.com/pypi/simple/ "paramiko>=3.5,<5"
```

SSH 凭据通过 `RIGHTS_SSH_CREDENTIALS_PATH` 指定受保护文件；当前默认使用用户明确授权的腾讯云 SSH 技能 `.env`。主机公钥从当前 Windows 用户 `.ssh/known_hosts` 核验，未知/变化的公钥拒绝连接。新电脑需核实主机指纹后配置自己的凭据及 known_hosts，不复制私钥正文到文档。

数据库连接目前读取采集项目已存在的受保护 `config.json`，所有 MCP 查询使用固定 SQL 和只读事务。**没有新增数据库角色或修改权限，因此不是独立 SELECT-only 账号隔离**；后续管理员可配置专用 MySQL 只读账号文件，通过 `PRICE_MONITOR_CONFIG` 指定，避免长期复用采集连接账户。本次未新增数据库账号或变更表结构。

台账新增/修改后刷新页面或重新查询即可读到数据库；不再需要生成本地 JSON。导出校验当前数据版本，版本变化时要求重新查询，不静默截断；单次最多5,000条，超限需缩小筛选范围。

## 排查和回退

云端只读检查：`systemctl status price-rights-mcp.service`、`ss -lnt`。采集仍由独立任务维护；不要用 MCP 启动或补跑采集。

本地通道日志：`runtime/rights-tunnel.log`。若网页报错，检查 SSH 配置/主机公钥、云端服务、专用 Token；不要恢复读取本地快照来掩盖异常。

云端v1发布目录保留，服务配置备份为 `/opt/price-monitor/rights-mcp/price-rights-mcp.service.v1.backup`。需要回退时，仅恢复该服务的 WorkingDirectory/ExecStart 到v1并重新加载/重启 `price-rights-mcp.service`；不删除目录、不重启采集和其他服务。

本地配置备份 `runtime/rights-cloud-before.env` 包含敏感配置，已列入 Git 忽略，不要上传或发给他人。回退旧146读取属于显式人工应急动作，必须同时注明数据过期，不作为自动回退。
