## 本次改动

- 146 `/mcp/reputation` 增加 `reputation_search_source_reviews`，现有 7 个工具保留，共 8 个工具。
- 状态接口增加原始数量、平台分布、来源车型名称数、与新车精确匹配名称数、最新发布日期、最近记录更新及存储信息。
- 原文查询采用数据库分页、绑定参数与只读 REPEATABLE READ 事务；页内数量和内容同一快照，跨页检查来源版本变化。
- 版本依赖采集侧维护 `updated_at`；来源版本并非标签分析版本。`last_record_update` 不是采集任务成功时间。
- 只给已有 `market_mcp_reader` 增加两张原始表的 SELECT 权限，无表结构变化。
- 三处展示共用智能体口碑插件 URL、启用开关和服务端凭据；页面不持有数据库或 MCP 凭据。
- 移除 8765 看板和静态回退、没有计算来源的统一情感分、趋势图及“每周重新评分”等演示陈述。
- 新增 `/reputation-detail` 原文检索：精确车型、平台、关键词、分页、平台原始评分及来源链接。
- 车型详情增加最新原文入口；仅没有标签时明确“原始口碑已入库，标签分析尚未覆盖”。真正无精确来源样本与 MCP 服务失败独立处理。
- 模型关联仅来源车型/采集输入名精确匹配，明细也允许来源 `carname` 精确匹配；不按评论提及竞争车型归属。别名不匹配不代表全网无口碑。车系标准化映射需维护端后续确认。
- 原文列表不读取或展示作者账号、用户 ID、购车位置等额外个人字段。
- 标签树叶子统计来自现有 MCP；父级去重统计未返回时显示“—”，不能相加重叠叶子数冒充去重口碑。
