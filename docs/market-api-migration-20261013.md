## 性能与完整性

概览成功结果缓存60秒，并发请求合并，异常不回退旧数据。HTTP 客户端按事件循环、端点和凭据复用，首次证书初始化在线程中完成。页面加载不再发现 MCP 工具。详情和证据在数据库分页；前端筛选的完整列表通过单事务快照返回，最大10000条，超限明确报错。

新车卡片日期格式为 YYYY-MM-DD：优先使用表记录的更新时间/入库时间/创建时间；没有这些列时使用库内记录日期，并标注“库内最新日期”，不将上市日冒称入库时间。

已在页面确认：`正式批次 202609 · 库内最新日期：2026-09-30`。
