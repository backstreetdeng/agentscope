## 3. 磁贴② 购车关注

|---|---|---|---|---|
| 关注结构·第一排序占比 | 无 | 原型按「第一排序」分产品/品牌/服务三类；库内无排序题 | — | **不可做** |

| 分车型关注 TOP5 | 同上 | 按勾选率排序取前 5 | 同上 | 可做 |
| 核心关注首选率 | `Q3_13__N` ∩ `Q3_23__N` | 建议口径：勾选关注 N 的人中，最终因 N 选择该车的人数 ÷ 勾选关注 N 的人数 | 单维分母 2–9 人，过小 | **可定义但多数车型不可展示**（分母 <10 不展示） |

- 「第一排序」不可做的证据：`quant_question` 中检索「排序」0 条；`Q3_13` 是多选勾选题，答案里没有排序权重。深访 Q20 虽问 TOP5 关注，但是自由文本且每车 3–4 人，不能反推成三分类占比。
- 页面改法：把原型的「产品/品牌/服务 第一排序」替换为「16 维关注勾选率 TOP5 + 全部 16 维明细」；标题写明「多选勾选率（可多选，不等于第一关注）」。

| 满意度 TOP5 / 不满意 TOP5 | 同上 | 按均分排序，附低分率 | 100% | 可做 |
| 整体满意度 | `Q5_1`（2–10 分） | 均值；全库 8.52（n=1380） | 30–41/车，100% | 可做 |
| 推荐意愿 | `Q5_5` | 文本「9十分推荐」取前导整数 → 1–10 均值 + 分档 | 各车型 = 总样本（41/39/30/31/30） | **可做**（更正原「0 条作答」） |
| 口碑正/负向标签 | `public.new_car_reputation_summary` | 按 `mention_count` 排序；口径为外部评论标签，非本库问卷 | 五车 39–730 条 | 可做，须标「外部口碑，非问卷」 |
| 本品进攻点 | 本车高分维度 vs 对比车型低分维度 | 推导口径：本车均分 ≥ 对比车均分 + 1 且本车低分率 ≤ 对比车 | 可算 | 可做，标「推导」 |
| 本品被进攻点 | 反向规则 | 同上 | 可算 | 可做，标「推导」 |

- 实测示例（五车口碑正/负 TOP1）：零跑B10 正向「配置智能」120 / 负向「油耗能耗」39；铂智3X 正向「空间」10 / 负向「舒适性」17；iCAR 超级V23 正向「外观」26 / 负向「舒适性」28；海狮05 EV 正向「外观」5 / 负向「舒适性」12；钛3 正向「配置智能」227 / 负向「舒适性」53。
- 口碑表车型名与问卷车型名不一致：`iCAR 超级V23` ↔ `奇瑞iCAR V23`、`MG 07` ↔ `MG07`、`小鹏MONA M03` ↔ `小鹏M03`。必须集中维护别名映射，不能散落在 SQL 里。
- 「进攻点/被进攻点」不是原始题项，页面必须标「基于满意度差值推导」，并给出参与比较的两车与两侧样本数。

## 6. 自然语言综合结论

- v1 采用**确定性模板**：由后端把上面已算出的真实数字拼装成 3–5 条结论，每条带「车型、指标、数值、样本量」。
- 不接 LLM 自由生成，理由：原型里的结论是人工写的；LLM 在没有新数据的情况下只会复述或编造，违反「绝不编数据」。
- 模板示例（零跑B10）：
  - 「零跑B10 定量样本 41 人，深访 4 人；62% 为首购（25/41）。」
  - 「满意度最高维度为 X（均分 x.x，n=41），最低维度为 Y（均分 y.y，低分率 z/41）。」
  - 「放弃核心对比车型的主要原因：外观 15/41、空间 12/41、内饰 11/41。」
- 当某磁贴指标不可用时，结论不写该项，并在页面空态卡片里保留原因，不能让模板编一个中性说法。

## 7. 样本量与空态展示规则

| 场景 | 规则 |
|---|---|
| 车型定量总样本 <10 | 不展示比例，只展示人数；卡片标「样本不足」 |
| 10 ≤ 样本 <30 | 展示比例 + 「小样本」标记；同时给分子分母 |
| 样本 ≥30 | 正常展示；仍给分子分母 |
| 题目作答人数 <10 | 该指标显示空态：「本题仅 n 人作答，低于展示门槛」，不计算比例 |
| 数据源整源为空（如无排序题、无对手视角题） | 显示「库内无对应题项」+ 题号/说明，不显示 0% |
| 口碑/配置缺失 | 该卡片单独空态，不影响问卷类磁贴 |
