## 拟议技术方案（待确认）

1. **数据与时点**：复用已校验的月度零售序列；外部变量另建本地、版本化的对齐接口，记录指标定义、单位、地区、统计月份、发布日期、来源和缺失方式。只有预测起点时实际已知的数据可进入回测；当前仅有修订后历史快照时必须注明无法复原当时版本，不宣称完全避免修订泄漏。
2. **分层实施**：先在不引入外部变量的情况下建立可复现的季节性统计基线；有经业务确认的外部数据后，再增加变量、滞后项和统计诊断。两者分别标识，不能把无变量基线包装成因素分析。
3. **预测与情景**：独立模型适配器输出统一的预测月份、点预测、区间、模型/参数、训练截止、来源版本和模型状态。用户选择基准情景由业务提供明确假设；缺少未来变量时拒绝该外生预测或清晰提示，并不使用未来真实值。假设变化应重新计算，注明统计情景而非因果推断；SARIMAX 条件预测区间需注明模型假设、单独核验覆盖率，不能声称与 Chronos 区间校准等价。
4. **建模与诊断**：按实际样本长度和覆盖选择有限的季节周期、模型阶数与滞后候选；参数选择仅在各回测起点之前进行，限制计算成本。检查缺失、零值、常数序列、单位、收敛和数值稳定；不收敛或不足时明确失败，不能伪造预测或无提示切换模型。统计显著性需结合样本量、共线性和残差诊断，不保证变量有业务解释价值。
5. **公平回测**：与 Chronos-2 和季节性基线共享预测对象、数据版本、历史截止及滚动起点，分别报告 1/3/6/12 月 MAE、WAPE、有效样本数和区间覆盖。零实际值时 WAPE 分母为零应明确不可计算，不以数值替代；保留逐起点回执。对比是预测效能比较，不构成正式精度验收。
6. **展示与调用**：拟在现有“新版-市场预测”中以独立模型选项或并列视图呈现结果和比较，复用统一数据约定，具体交互及 API 契约先核对并确认；DeepSeek 仅接收现有质量门允许的未来预测信息，不新增外发历史或回测内容。
