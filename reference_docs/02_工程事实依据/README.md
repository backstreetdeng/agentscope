## 维护规则

1. 修改接口、Schema 或架构设计时，**只更新本目录**，并与对应代码变更一起进行版本管理。
2. 数据底座需要重新交付时，从本目录**单向复制**对应文档，标注版本号、生成日期和来源，不允许反向修改真源。
3. 原始数据的数量、质量、校验值等**事实**，仍以数据底座 `00_manifest/` 中的实际清单、质量报告和校验文件为准。
4. 若工程文档与实际代码、数据库存在不一致，必须记录差异并核实，不得直接假设文档或代码必然正确。
