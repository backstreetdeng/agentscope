# 用户洞察自动打标签方案

## 输入数据

- 用户访谈音频 ASR 转写稿
- 群访谈音频 ASR 转写稿
- 深访逐字稿
- 车主口碑评论
- 社媒评论
- 销售线索备注

## 推荐流程

```text
音频/评论原文
  -> ASR 转写或文本清洗
  -> 隐私脱敏
  -> 片段切分
  -> user_insight_tagger 自动打标签
  -> 人工抽样复核
  -> 标签表/需求矩阵/向量索引
  -> 用户洞察 Agent 检索和分析
```

## 标签体系

- 用户圈层：城市家庭、年轻首购、增换购、运营用户、科技尝鲜。
- 需求标签：续航补能、智能驾驶、智能座舱、空间舒适、安全可靠、价格价值。
- 配置诉求：800V 高压平台、热泵空调、激光雷达、大电池长续航、舒适座椅、智能座舱芯片、家庭娱乐配置。
- 情绪倾向：positive、neutral、negative。
- 付费意愿：必须有、可选装、无感知、反感。

## 冷启动策略

当前 `user_insight_tagger` 是规则+词典工具，适合没有高质量数据集时冷启动。

后续升级路线：

1. 收集 50-100 条访谈片段，人工复核标签。
2. 把复核结果作为 few-shot 样例，升级 LLM 标签抽取 Prompt。
3. 积累 1000+ 条后训练轻量分类器或构建标签评估集。
4. 将标签片段写入向量库，支持“相似用户原声证据检索”。
