# 数据资产规划

本目录用于沉淀市场决策和用户洞察数据。当前只放目录说明，不提交真实业务数据。

推荐分层：

```text
data/
├── raw/                 # 原始数据，尽量不改动
├── processed/           # 清洗后的结构化数据
├── labels/              # 用户标签、需求标签、配置标签
├── index/               # 向量索引或检索索引
└── schemas/             # 字段说明、标签体系、数据质量规则
```

数据质量要求：

- 每条数据必须保留来源、时间、采集方式。
- 用户访谈、电话、评论中涉及个人信息时必须脱敏。
- 销量、上险、批发、零售、交付口径必须明确区分。
- Agent 输出使用数据时，必须能回溯证据。
