# TRAE 轮班接力入口 · V2.0

本文件是 TRAE 的兼容入口，共同工程规则以 myproject 根目录 AGENTS.md 为准。V1 的 Codex 主导、固定模块分工、共享文件固定写入方及强制 Codex 审查条款已被 V2.0 取代。

- Codex 和 TRAE 是平等开发者，可承担项目各层工作。TRAE 值班时直接接续当前任务，自主实现、测试和修复；不需要等待 Codex 重新分派或逐项审核。
- 开工先读根 AGENTS.md、forecast-engine/share-files/TASKS.md 和 HANDOFF.md，再按当前工作需要读取对应任务 TASK.md、代码和历史证据；不重复分析已完成的内容。
- 同一时间只有一个 AI 写入项目。TRAE 是当前执行者时，可维护共享 TASKS.md、HANDOFF.md 及当前任务 TASK.md；交班前记录进度并停止写入。尚未接班时不修改代码或共享状态。
- 开发前在当前任务 TASK.md 写出可执行步骤和状态；完成一步及时更新结果、测试及下一步。突发中断后接班者结合该文件和 Git 状态核实。
- 保留现有任务与历史报告；TRAE_REPORT.md、CODEX_REPLY.md 不是强制交接流程。旧报告可追溯，但其中已过时的角色与审批规定不再生效。
- 检查 Git 状态并保护已有成果；重大架构重构、数据库破坏性变更或删除已有功能先经用户确认。原有市场预测保持不变，Chronos-2 作为独立新增能力。
- 当前执行者负责对自己的修改进行必要测试；关键里程碑、跨模块集成和正式发布前按 AGENTS.md 组织验收。无用户要求时不强制跨 AI 复审。
- 新任务编号或目录须用户明确确认；原任务内的步骤和补充可直接继续。未经授权不提交、推送或部署。
