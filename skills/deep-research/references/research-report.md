# 研究报告模板（D2）

适用：单一主题的系统性研究（技术趋势、市场格局、政策影响、用户现象等）。深度 L2-L3。

## 章节结构（必需章节加粗）

1. **结论摘要**（≤5 条要点；事实带 [cite:N]；判断标注置信度）
2. 背景与研究问题
   - 为什么研究、要回答什么、边界与时间范围
3. 现状分析
   - 分主题小节陈述已验证事实，每条事实带 [cite:N]
   - 定量数据标注统计口径与时间窗
4. 关键发现
   - 每条发现 = 事实依据（[cite:N]）+ 解读；多重解读并列时不武断择一
5. 趋势与展望
   - 以"判断/研究假设"身份出现，注明依据与不确定性
6. **缺口声明**
   - `[数据不足]` 条目逐条列出，附建议补证路径
7. **参考来源**
   - `N. 标题 — URL（层级 P0-P3，时点）`
   - 层级说明：P0 官方申报/公告、P1 权威媒体/白皮书、P2 专业评测、P3 论坛百科（仅线索）

## 引用体系

- 正文引用格式 `[cite:N]`；同一句多个来源可并列 `[cite:1][cite:2]`
- `[cite:N]` 必须能解析到参考来源清单，虚构引用视为验收失败
- 定量结论只用 P0/P1；仅 P3 支撑的写 `[待核实]`
- 相互转载不算独立来源；核心论点 ≥3 独立来源后才可作为确定性结论

## 格式要求

- GitHub Flavored Markdown；标题层级从 `#` 开始依序嵌套
- 表格用于多维数据；不贴无关长代码/日志
- 独立成文：不依赖聊天上下文即可读懂
- 长度 L2 约 1500-3000 字；L3 可放宽至 5000 字，宁可缺口声明也不灌水
