# 对比分析模板（D1）

适用：两个及以上车型/技术/方案的优劣势比较。深度默认 L2。

## 章节结构（必需章节加粗）

1. **结论摘要**（≤5 条要点；每条标注事实或判断；判断注明置信度 高/中/低）
2. 对比对象与口径
   - 各对象的基本定位、价格区间、目标人群（带 [cite:N]）
   - 明确对比维度与数据时点（as_of）
3. 分维度对比
   - 硬参数类（续航/电池/能耗/尺寸等）：P0 申报口径优先，宣传值仅佐证并标注口径
   - 市场表现类（销量/价格走势）：P1 来源，标注统计口径与时间窗
   - 口碑/体验类：口碑 MCP 或 P2 评测，标注平台与样本性质
   - 维度用表格呈现：维度 | 对象A | 对象B | 来源 | 口径备注
4. 冲突与分歧点
   - 来源数值冲突时双边呈现：数值A（来源，口径）vs 数值B（来源，口径），分歧原因
5. 判断与建议（So What）
   - 机会/威胁/取舍建议，每条带置信度与支撑来源
   - 推断必须标注"判断/研究假设"，与事实分开
6. **缺口声明**
   - 检索不到或证据不足的维度逐条列出，标 `[数据不足]`
7. **参考来源**
   - 编号清单：`N. 标题 — URL（层级，时点）`
   - 正文所有 [cite:N] 必须对应本清单

## 质量要求

- 每个对比维度至少 1 个可解析引用；核心维度 ≥2 独立来源
- 硬参数冲突以 P0 申报口径为准并注明
- 不合并不同口径数值（CLTC vs WLTC、指导价 vs 成交价分列）
- 全文不出现无来源的绝对化断言
