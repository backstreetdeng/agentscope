# 新月份独立生成与人工月报对照

收到材料后再执行。当前仅完成2.0接入及6月离线回归，不代表新月份已通过业务验收。

## 输入登记

- 新月份验数Excel及目标Sheet；记录文件SHA256、统计年份/月、单位、范围和修订时间。
- 同月份人工完成PPT；作为评估基准保存，独立生成AI初版前不提取其中的分析结论。
- 补充数据口径和新月份业务材料，尤其P4右侧典型新车明细。
- 固定2.0技能、模板版本、模型配置和当月证据范围；不使用人工目标报告作为生成模板。

## 独立生成

1. 检查Excel是否符合18个页块映射，结构变化时先对照字段，不按旧坐标强行读取。
2. 显式传递dataset_path和sheet_name完成输入预检；不覆盖6月默认样例。
3. 按已接入的市场战略Agent月报流程生成Markdown和23页可编辑PPT。
4. 保留原始AI输出、质量门禁、数据来源和生成配置；存在缺口时单独标记。
5. 冻结AI初版后再读取人工PPT，修订版另存，不能用修订版替代初版评估。

## 逐页对照

每页记录：人工值/表述、AI值/表述、Excel证据位置、差异、原因、建议与复核状态。

| 维度 | 检查内容 |
| --- | --- |
| 结构 | 23页顺序、内容覆盖、区域和新能源拆页 |
| 数据 | 销量、同比/环比、份额、累计、单位、排序及TOP车型 |
| 分析 | 主结论、代表车型、变化解释、证据支持、遗漏或过度归因 |
| 版式 | 字号配色、图表可编辑性、文本溢出、注释与标签位置 |
| 边界 | 缺失值、口径、跨月内容、保留模板区域及不确定性披露 |

人工版不是自动正确答案。数值冲突回到Excel和业务口径核验；原因归为映射、计算、
文案、证据、排版、人工差错或待业务确认。汇总关键数值一致率与需修正项时列明分母。

交付AI初版、逐页差异表、问题汇总，以及必要的单独修订版。评估后有依据地修正Skill。
