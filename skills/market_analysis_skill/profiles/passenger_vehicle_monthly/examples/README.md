# 少样本案例说明

少样本案例应成对保存：

```text
case_id/
├── input_snapshot.xlsx
├── expert_output.pptx
├── expert_text.md
├── evidence.json
└── acceptance.yaml
```

当前安装包不复制完整专家月报案例，只打包经批准的业务母版和演示验数数据。项目内已有 2026 年 3 月、4 月、5 月专家样例，可在确认共享权限后按上述结构加入。

每个案例应标注：统计口径、报告月份、页面、标准标题、标准分析段落、选用车型、原因证据和质量验收项。不能只存 PPT 截图，否则无法自动检查数据与文字是否一致。
