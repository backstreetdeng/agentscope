# 月报 2.0 数据契约

## 1. 输入布局

默认输入为一个 `.xlsx` 工作簿中的单个月份 Sheet。Sheet 名使用 `1月` 至 `12月`，A 列按以下页面标记纵向分块：

```text
P3-整体市场
P4-新车
P5-库存
P7-车型类别
...
P21-TOP20车型
```

必须出现 18 个内容页标记：P3、P4、P5、P7-P21。每个标记到下一个标记前的所有行属于该页。精确区块和处理器见 `excel_v2_mapping.yaml`。

## 2. 通用字段约定

- 年份从以 `20xx` 开头的年份表头识别；不得从车型名称或小数中提取。
- 销量允许使用“辆”或“万辆”，同一数据区块必须口径一致。
- 同比、环比、份额使用 Excel 小数值；渲染时转为百分比。
- 普通表格正增长不显示 `+`；排名变化、强调气泡和份额变化沿用业务母版符号。
- `#DIV/0!`、`#N/A` 等无同期缓存值显示为 `-`，同时输出公式错误警告。
- 空白和短横线不是零；不得参与同比、份额加总或排名计算。

## 3. 页面级字段

- P3：月度销量、月度同比、累计销量、累计同比。
- P4：新车增量贡献、新车数量、车均销量、同比贡献度；右侧典型新车为可选补充区。
- P5：库存量、存销比，含传统车与新能源分项。
- P7/P8/P12/P13/P15：`左图上`、`左图下`、`右图` 三段结构；P8允许在`右图`后额外出现`行标签`。
- P9/P10/P11：级别月度/累计/份额，另含15名车型明细：车型、销量、同比、环比、级别、份额、排名变化、累计。
- P14：31省份销量与同比，以及东/中/西部汇总。
- P16：当月与累计TOP15企业及同比。
- P17：新能源销量、同比/环比、累计、渗透率。
- P18：BEV/PHEV与传统能源形式对比。
- P19：BEV和PHEV分级别月度、累计、同比、环比、份额。
- P20：新能源当月与累计TOP10企业。
- P21：当月TOP20、累计TOP20及两组跨列`累计份额`。

## 4. P4缺数处理

业务提供的6月验数表没有P4右侧“典型新车增量贡献”子图明细。规则如下：

1. 当报告期为2026年6月且使用已验收业务母版时，保留母版右侧内容并输出警告。
2. 其他月份必须补充车型、销量/增量、时间范围等字段；否则该区块降级为草稿。
3. 禁止根据左侧总量反推或编造单车数据。
