# 周度资讯快报自动生成：完整能力包

网页入口：`/weekly-report.html`，技能标识：`auto-weekly-report`。

包内包含原始提示词Word、原始SKILL、最高优先级校准、逐板块检索知识、版式规则、历史去重台账、参考成稿、可移植Word模板、原三份生成脚本与新增独立验收器；`scripts/web_runtime`固定网页执行器和联网研究器。原始来源目录保持只读。

每轮建立独立任务工作区，固定包版本和用户日期，逐板块挂载原文读取、检索、历史核验及结构化提交工具；脚本生成和独立内容/文件验收由后台实际执行。已取得原文有文件指纹，已验收板块直接复用；跨服务同一任务使用操作系统文件锁。

最终一次性交付HTML阅读版、Word正报及来源Word，顺序固定。Word克隆原模板，保留图片、样式、原生自动编号与两节结构；封面日期、装饰年份和跨年范围动态更新。可用时调用本机Word兼容COM更新目录和导出PDF进行实机验收。

`package-integrity.json`封存全部资源与执行器。网页运行依赖宿主AgentScope 2.0.3、已配置模型、agent-reach/Exa公共检索和网页正文读取；这些是运行时工具与配置，不是模型训练。实际检索的新闻不得由参考成稿或离线测试数据替代。

原始操作标准及冲突解释见`references/runtime-contract.md`。单元测试使用明确标识的合成证据，只验证执行与门禁；真实检索验收独立记录，不混作真实资讯。
