# 网页周报运行契约

原包解读：周报提示词.docx是SKILL说明的Word版，规定联网检索、九章正文、模板克隆及三件套。search_prompts.md包含逐板块细则和后续业务校准；report_rules.md规定结构/编号/去重；coverage_log.md是已有报道基准。三个生成脚本均须实际执行，doc/历史样例只用于版式参考。

优先级：本次明确用户要求 > 2026-10-10最高优先级校准 > 逐板块规则 > 旧通用规则。2026-08日期是历史示例，不能覆盖本轮输入。合并期允许12–13摘要；普通周采用9–10（满足原“须大于8”）。宏观官方指数可保留，排除的是汽车行业/企业运营数据与政策成效统计，不能误删PMI等宏观事实。企业海外、行业外国政策、预告/招标/申报均剔除。

目标条数是检索目标，不是造资讯许可。九章必须保留；某板块不足时记录具体缺口与已检索证据，未通过的正式报告不得发布。合资来源争取≥3主体、上汽系≤2；数量不足的范围需明确提示。

事件证据字段：source_id实际抓取记录，event_quote逐字摘录含日期与已发生动作；event_date为ISO完整日期；title/body/date/source三件套共用。新车另附车系历史核验source_id及quote，来源限汽车之家/易车，无法证明首次车系则剔除。模型不得自行创建来源ID。

输入支持YYYY-MM-DD开始和结束、模型选项、说明。默认最近完整周，未来截止日不收。当前客户端日期和显示均为Asia/Shanghai。结束日跨年使用完整起止日期，文件名和来源文档年度动态更新。

完整包包含原始规则、提示词Word、提取原文、三篇样例、三份生成程序和新增验收器。assets/weekly-template.docx来自2026.0926-1010原始样例；模板仅克隆，不覆盖。目录域由Word更新，不能生成虚假页码。持久化去重状态在data/weekly-report/，任务副本留存当时台账快照，只有三件套验收通过后追加。

任务阶段：装载资源→十四板块检索/事实核验→摘要与全篇门禁→运行三份脚本→Word/HTML独立验收→归档及台账。每阶段保存工作区内相对路径和SHA256，重启恢复不得访问“最近一次”其他任务的资源。

合并期摘要沿用2026-10-10的12–13条总量及宏观/政策/企业重头/新车优先口径；先覆盖各组，再从同一正文补足。常规周各组1–2条是建议分配，不得让固定两条的内部候选池使合并期无法达到12条；所有摘要仍须逐字复制通过核验的正文。
