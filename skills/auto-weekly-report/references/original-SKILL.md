# 中国汽车产业周度资讯快报自动生成

## 概述

- **联网搜索模式（默认）**：AI 按 `references/search_prompts.md` 中九个章节各自的搜索链接、关键词、日期范围与筛选规则，逐一联网检索（盖世汽车 gasgoo 各版块 + 百度/行业媒体），撰写全部内容并直接生成九大章节总报告 `中国汽车产业周度资讯快报2026.MMDD-MMDD.docx`。

最终通过 `scripts/gen_report.py` 以模板克隆方式生成文档，保留原始 XML 结构、样式、图片和文本框。

**最终交付三件套**（缺一不可，一次性 `present_files` 抛出）：

| 顺序 | 产物 | 用途 | 生成脚本 |
|---|---|---|---|
| 1 | `中国汽车产业周度资讯快报2026.MMDD-MMDD.html` | **可视化阅读版**（浅色主题、图文并茂） | `scripts/gen_visual_html.py` |
| 2 | `中国汽车产业周度资讯快报2026.MMDD-MMDD.docx` | 归档正报（模板克隆） | `scripts/gen_report.py` |

> 本模式把「五个同事分版块查资料」的工作全部交给 AI：用户把各版块提示词汇总进 `references/search_prompts.md`，AI 据此联网搜索并产出九大章节总报告。
> **首跑任务日期范围：2026.08.01 - 2026.08.07（上周六~本周五）。** 后续每周整体平移日期即可。

读取 `references/search_prompts.md`，确认本任务的日期范围，以及九个章节各自的搜索链接、关键词、条数、标题/正文规则与 JSON 去向。该文件是搜索与撰写的最终依据。

**搜索执行建议**：
- gasgoo 版块：用 WebFetch 抓取列表页提取「已有标题」（标题沿用、不改写），再对重点条目 WebSearch/WebFetch 补充内容；或直接 `WebSearch "site:auto.gasgoo.com <关键词> 2026年8月"`。
- 新车上市：先在 `https://price.pcauto.com.cn/cars/6/` 找本周上市/预售车型（全新优先，无全新则取大销量改款），再到百度补售价/配置资讯。
- 凡 `search_prompts.md` 标注「标题沿用链接已有标题」的板块（自主/新势力、豪华、零部件、战略、新技术），**标题一字不改，描述取主要內容**，不重写。

#### 第三步：撰写 report_data.json

按 `search_prompts.md` 末尾的 JSON 结构编写（九大章节顺序、各 subsection 严格对应；完整规则见 `references/report_rules.md`）。

```json
{
  "summary": [ {"title": "...", "body": "..."} ],
  "body_sections": [
    {"section": "政策法规", "subsection": "", "items": [{"title": "...", "body": "..."}]},
    {"section": "企业要闻", "subsection": "豪华品牌车企", "items": [...]}
  ],
  "toc": ["章节标题\t页码", ...]
}
```

**⚠️ JSON 引号注意**：正文中的中文引号应使用弯引号 `""`（U+201C/U+201D），不要使用 ASCII 直引号 `"`（U+0022），否则会破坏 JSON 解析。若已混入，使用 `fix_json.py` 修复（与 `gen_report.py` 同目录）。

**摘要选择要点**（详见 `report_rules.md` 第六章）：
- 条数：8-10条（须大于8条）
- 内容：直接复制正文原文，不修改不改写
- 顺序：政策→宏观→企业→新车
- 政策1-2条：省级/重要城市优先，不放区级
- 宏观1-2条：促消费、重点指数（PMI等）
- 企业：豪华优先国内、全球可；合资/自主/新势力各1-2条
- 新车1-2条：只放全新车，改款不放（除非热门）
- 不放：技术、零部件、月度/半年度交付量等常规运营数据；**企业销量/财报/当月乘用车销量等周期性数据新闻一律不放（正文与摘要均不收，永久规则）**

#### 第四步：运行 gen_report.py 生成文档

```bash
python scripts/gen_report.py \
    --template "E:/ASUS/桌面1/中汽数据实习/0报告们/2026年部分周报/4月/中国汽车产业周度资讯快报2026.0509-0515.docx" \
    --output "中国汽车产业周度资讯快报2026.0801-0807.docx" \
    --data report_data.json \
    --date-old "05.09-05.15" --date-new "08.01-08.07"
```

- `--date-old`：模板中的日期（05.09-05.15），支持带或不带前导零（脚本会自动去前导零匹配拆分的 w:t 元素）
- `--date-new`：本周日期（上周六~本周五，格式 MM.DD-MM.DD），支持带或不带前导零
- `--output`：九大章节总报告，命名 `中国汽车产业周度资讯快报2026.MMDD-MMDD.docx`（这是最终产物；原同事的「周度资讯 自主品牌+造车新势力2026XXXX」等分版块文件已并入本总报告，不再单独产出）

#### 第五步：生成可视化 HTML 阅读版（必做，与 docx 一并交付）

> **2026-10-08 用户指令**：周报做完后**自动附带**一份可视化 HTML。docx 是归档件，HTML 是阅读件，**两者必须同时交付**，不要再问用户要不要。

```bash
python scripts/gen_visual_html.py \
    --data report_data.json \
    --date-new "09.30-10.06" \
    --output "中国汽车产业周度资讯快报2026.0930-1006.html" \
    --title-prefix "中国汽车产业" \
    --report-date "2026.10.08"
```

脚本自动完成：Hero 头图 → KPI 大数字卡 → sticky 胶囊导航 → 摘要卡 → 九大板块（各配专属颜色）→ 关键数据图表 → 时间轴 → 本期观察 → 来源清单 → 口径说明页脚。**单文件、零外链依赖、浅色主题**，双击即可打开。

**⚠️ 写入 `report_data.json` 时必须同时补两个字段**，否则可视化版会缺料：

| 字段 | 位置 | 作用 |
|------|------|------|
| `date` | 每条 `items[]` 内，如 `"10.01"` | 渲染日期标签；同时供来源表使用 |
| `visual` | JSON 顶层（可选） | 驱动 KPI / 图表 / 时间轴 / 本期观察等增强块 |

`visual` 结构（全部可选，缺省自动跳过，不影响出图）：

```json
"visual": {
  "hook_title": "本周车市，发生了这 N 件事",
  "hook_sub": "一句话导语",
  "kpis": [ {"num":"6.8","unit":"万辆","label":"汽车以旧换新量\n带动新车销售额 109.2 亿元"} ],
  "section_leads": { "政策法规": "这板块的一句话导语" },
  "bars": [ {"title":"标题","note":"副标题","rows":[
      {"k":"10.1—10.3","label":"4.6 万辆","pct":67.6,"color":"#93c5fd","v":"74.5 亿"} ]} ],
  "donut": {"title":"标题","note":"副标题","pct":62,"label":"中国份额","label_value":"62%","color":"#0ea5e9",
            "legend":[{"text":"中国","value":"62%","color":"#0ea5e9"}]},
  "timeline": [ {"date":"10.10","name":"车型名","desc":"一句话","done":false} ],
  "insights": [ {"title":"判断标题","body":"正文"} ],
  "footer_note": "自定义口径说明（可选）"
}
```

- `kpis` 最多渲染 5 个，超出会被截断；只挑最硬的数字。
- `bars[].rows[].pct` 按该组最大值归一化到 0–100，**脚本不做归一化计算，需自己算好百分比**。
- `timeline[].done` 为 `true` 时节点实心（已发生），`false` 空心（已定档待发生）。
- `insights` 渲染为「本期观察」，建议 3 条。
- 正文 `items[].body` **支持内联 HTML**（如 `<b>7000 元</b>`），但引号须用中文弯引号 `""`。

脚本自带自检，输出 `[OK] 已生成 … 板块数 x ｜ 资讯卡 y ｜ 字符数 z ｜ 乱码字符 0`。若 `乱码字符 > 0` 会以退出码 2 报警，需先修 `report_data.json`。

生成后**必须**用 `present_files` 同时交付 docx、HTML、来源 docx 三个文件，**HTML 放第一个**（优先预览）。

## 注意事项

- **必须使用模板克隆**：`shutil.copy2(TEMPLATE, OUTPUT)` 后替换内容，不可从零创建文档
- **目录与正文之间用分页符**（`w:br type=page`），非分节符，确保只有2个分节
- **编号由 Word 自动生成**：章节标题 numId=2（一、二、三…），条目标题 numId=6（1,2,3…全文连续）
- **封面日期跨多个 w:t 元素**：日期如 "07.25-07.31" 被拆分为 ['25-2', '31'] 等，需逐元素替换；月份被拆分为 ['0', '5'] 等，parse_date 会自动去除前导零
- **摘要内容必须与正文原文完全一致**，不可改写
- **JSON 中的引号**：正文内容中的引号应使用中文弯引号 `""`（U+201C/U+201D），不可使用 ASCII 直引号 `"`（U+0022），否则破坏 JSON 解析。若已混入，运行 `fix_json.py` 修复
- **生成前检查 JSON 乱码**：写入 report_data.json 后先用 Python 扫描 `content.count('\ufffd')`，若 >0 则按上下文语义修复（UTF-8 字节损坏时 1 个汉字会变成 2 个 `�`，如"出厂价格��数"→"出厂价格指数"、"环比上��0.3%"→"环比上涨0.3%"），确认无 `\ufffd` 且 `json.loads` 通过后再运行 gen_report.py
- **交付三件套（2026-10-08 起）**：每次周报产出的最终交付物为 **① 可视化 HTML（阅读版，排第一）→ ② docx 正报（归档版）→ ③ _来源.docx**，一次性用 `present_files` 全部抛出，不要分批、不要只给 docx。HTML 的生成见「第五步」，是**必做步骤**而非附加项。
- **`report_data.json` 的 `date` 字段要随手写全**：每条 `items` 都加 `"date":"MM.DD"`（事件真实发生日，不是报道日）。它同时服务可视化版的日期标签、来源表，以及回填 `coverage_log.md`，一次写全三处受用。
