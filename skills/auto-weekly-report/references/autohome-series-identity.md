# 汽车之家车系标签采集

用户每周提供一批车系，由当次对话触发采集。默认只查询和交付指定清单；不要自行扩大为全站输出、创建定时任务或发送消息。全目录模式仅用于用户明确要求全部带标签车系时。

## 固定口径

- 保留所有标签原文，不只筛选“新加车型”。已观察到搜索分类：新加车型、小改款、全新车系、中期改款、车系换代；未来出现新值也照录。
- 分开记录搜索提示 `tagname`、日期文案 `tagdate`、额外标签 `hottag` 与目录 `i[title]`。目录的“新车上市”“将上市”不能直接映射为搜索分类。
- 匹配车系 ID 优先；无 ID 时采用明确车系名称匹配，仅统一大小写、空白和全半角。不要把 MG4 匹配成 MG 4X、Model Y 匹配成 Model Y L，或把国产车系自动映射到进口车系。
- 不直接取搜索结果第一条。只处理 `wordtype == 3` 的车系记录；有多个候选时注明待核对，不做模糊猜配。
- 状态必须区分：匹配且有标签、匹配但无标签、未匹配、候选不唯一、查询失败。空标签不是“从未新增车型”。
- “是否新加车型”仅在准确匹配后按 `tagname == 新加车型` 判断；其他非空分类为否；空标签为未标注；未匹配/查询失败为待核实。
- 上市日期保存原文。接口通常只有月日，不推定年份；也不把该日期解释为整条车系的首次上市日。
- 公开页面未提供后端标签分配规则和保留天数，不编造固定时间窗口。

## 已验证来源

验证日期：2026-10-09。每次采集重新请求，不能复用旧标签作为本周结果。

搜索接口：
`https://sou.api.autohome.com.cn/sug/_suggest?plat=pc&uid=&q=<URL编码的车系名称>`

读取 `result.data[]`：`key`、`wordid`（车系ID）、`wordtype`、`tagname`、`tagdate`、`hottag`。
页面的“分类 + 日期”组合标签在 `wordtype == 3` 且 `tagname`、`tagdate` 都非空时显示；`hottag` 是独立展示字段。
无需用户 cookie 的请求曾验证成功。参数中的空 `uid` 可用，不读取个人浏览器凭据。

目录入口：`https://www.autohome.com.cn/car/`。
页面初次只装载部分字母。依据页面 `a[data-meto]` 与公开 waterfall 脚本，完整目录分组为：
`https://www.autohome.com.cn/grade/carhtml/<字母>.html`。
目录内提取车系 `h4 > a`、`h4 i[title]`、最近 `dl > dt` 的品牌、厂商、指导价。按车系 ID 去重。
2026-10-09 的 176 个带标签车系只是当日结果，绝不能硬编码为未来数量。

## 执行

1. 用户输入名称或链接已经明确时直接开始。把名单整理成 UTF-8 JSON 数组，保留顺序。数组元素可为名称/汽车之家链接，或 `{ "name": "Model Y", "series_id": 5769 }`。
2. 用 `load_workspace_dependencies` 提供的 Python 执行本技能的 `scripts/collect.py`（依赖 bundled lxml）。输出到当前任务可写目录；`--as-of` 采用当前客户端日期，每轮使用新的输出目录。

```text
python <skill>/scripts/collect.py --input names.json --out <task-output>/autohome_YYYYMMDD_HHMMSS --as-of YYYY-MM-DD
```

用户明确要求全目录带标签车系时，改用 `--all-tagged`（与 `--input` 互斥）。脚本为补充品牌和目录标签会读取目录分组，但指定清单模式只输出用户指定车系。

3. 阅读 `results.json` 的状态与候选；对异常可使用用户提供链接或车系页核对。接口失败最多自动重试一次；403/429 不循环重试。不把失败填成“无标签”。如果结构改变，检查车系页当前前端脚本中 `sug/_suggest`、`tagname`、`tagdate` 的实际逻辑，修正后继续；不要凭空猜接口。
4. 使用已安装 Spreadsheets 技能及 bundled artifact-tool 生成 Excel。默认一张结果表，含：输入名称、匹配车系、车系ID、品牌、厂商、搜索标签原文、日期文案原文、额外标签原文、目录标签、匹配状态、是否新加车型、指导价原文、采集日期、车系链接、搜索来源、目录来源。表头可筛选，冻结表头与名称列；保留空值和异常状态。必要的口径说明放在同一表，不复制额外汇总页。
5. 保留 `results.json` 与 `raw.json` 作为本轮快照。默认交付 Excel，简述实际数量、标签类别及未匹配项。来源链接留在表内。
6. 用户要求周间比较且上次结果可访问时，按车系 ID 比较搜索标签、日期文案和目录标签；名单不同不等于标签消失。没有前次数据时先完成本周采集，说明无法回溯对比。不得覆盖旧快照。

## 校验要点

指定模式输出行数必须与输入一致；未匹配也占一行。核对候选匹配、来源链接和异常状态，不使用本技能历史示例的标签/日期作为验收答案。全目录模式报告成功加载字母数及失败分组，部分加载不能称为全量。
