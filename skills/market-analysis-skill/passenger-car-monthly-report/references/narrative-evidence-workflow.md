# 主旨句异常触发与证据工作流

仅在生成分析版PPT或复核主旨句时阅读。数据版PPT不需要执行本流程。

## 输入

- 当前后台任务的 `run_id`、已完成批次清单和最近检查点。
- 当前月标准化数据包和PPT页映射。
- 至少上月同口径数据；使用“连续N个月”“首次”“再度”“历史最高/最低”时，必须提供覆盖该判断的完整历史窗口。
- 可用的政策、权益、新车、口碑插件状态。
- Tavily状态及是否允许公开联网查询。

## 异常触发

先生成事实候选，再选择主旨句。每个候选保留页码、指标ID、对象、当前值、比较值、单位和计算过程。

优先级从高到低：

1. `reversal`：同比/环比由正转负或由负转正，原优势市场转弱，原弱势市场转强。
2. `streak_change`：连续趋势延续、终止、扩大或收窄；必须有完整月份序列。
3. `structural_divergence`：细分市场与大盘方向相反，或不同能源、级别、价格段、系别明显分化。
4. `share_or_rank_shift`：份额、排名或渗透率发生显著迁移；同时判断分子增长还是分母收缩。
5. `contribution_concentration`：少数车型或企业解释了大部分增量/减量；必须有可复核贡献测算。
6. `ordinary_change`：普通高低值，只在没有更高优先级异常时作为主旨句。

阈值应结合页面指标波动和业务口径配置，不用固定百分点替代判断。一个页面最多选择一个主异常作为标题，其余进入正文。

## 证据路由

根据异常中的对象和待解释问题选择工具：

| 待解释问题 | 首选工具 | 关键字段 |
|---|---|---|
| 地方政策新增、暂停、到期或范围变化 | `policy_*` | 原文、发布日期、生效/到期日、区域、对象 |
| 促销、金融、置换及购车权益变化 | `rights_*` | 品牌车型、活动类型、金额、有效期、区域 |
| 新车上市、改款、换代和销量爬坡 | `new_car_*` | 车型、上市/改款日期、状态、月度销量 |
| 产品力、用户顾虑和评价变化 | `reputation_*` | 车型、时间、标签、样本量、原始证据 |
| 排产、交付、车展、油价、宏观和最新官方事件 | Tavily | 官方来源、发布日期、事件日期、适用对象 |

查询插件时先限定目标月份、对象和地区。Tavily查询只包含公开实体、时间和待核验事件，不包含内部销量快照、未公开业务数据或敏感字段。

插件和Tavily查询按异常对象分批执行。每批输出稳定的 `batch_id`、请求参数摘要、命中证据ID、失败项和重试次数。任务恢复时先读取检查点，禁止重复调用已经成功的查询批次。

## 证据等级

- `A`：结构化内部插件的原始记录，或政府、协会、企业官方原文；时间和对象完全匹配。
- `B`：权威行业媒体，或两个相互独立且一致的可信来源；时间和对象匹配。
- `C`：单一可信媒体、口碑聚合或间接线索，尚不能排除替代解释。
- `U`：无来源、时间不匹配、对象不匹配或只存在时间重合。

A/B级可以支撑正文中的确定性解释。C级只能使用“可能受到”“与……同期发生”等限定表达，通常不进入标题。U级不得进入主旨句或正文原因。

口碑数据只用于发现产品问题和用户顾虑线索，不能把评论热度写成总体需求强度。政策、权益、新车事件也不能仅凭同期发生就认定为唯一原因；应检查销量方向、影响对象、时间窗口和替代解释。

## 主旨句生成

除第9—11页专用车型规则外，其余分析页必须读取 [全页业务支撑规则](page-business-support.md)。后台实际执行具名事实提取、关系计算、模型润色、逐指标语义校验，不使用“数字在同页出现过”作为事实验证。

按以下结构组织，但不要机械拼接：

`对象 + 变化状态/拐点 + 经过验证的核心驱动或拖累`

规则：

- 标题先说明市场发生了什么，再决定是否加入原因。
- 同一标题只保留一个主判断和一个核心原因；多原因放正文。
- “渗透率提升”必须同时检查新能源销量和传统车分母，避免把分母收缩写成新能源繁荣。
- “主要贡献/拖累”需要贡献量或可复核的车型差额，不能只看排名。
- “新品驱动”需要上市/改款时间与销量增量同时成立。
- “政策带动”“促销带动”需要有效期、区域或车型与销量异常相匹配。
- 原因证据不足时，标题只写现象，正文列出待核验解释，不阻断数据版PPT。
- 有正文角色的分析页按一个高密度段落组织，目标约三行，覆盖核心现象、结构判断、必要支撑。第5页库存没有正文角色，只更新顶部页标题，保留图表标题、位置及尺寸；库存关系保存在本地作为标题/概述事实，不调用模型生成库存正文。
- “最多三行”是防止与图表重叠的上限，也是信息密度目标，不是把所有页面缩短为一两行。原文四行以上时，仅删除重复数字、低价值枚举并统一单位，必须保留结构判断和至少一个关键支撑。
- 只有当页面本身缺少第二、第三层事实时，正文才允许少于三行；不得为了视觉简短主动降级业务信息。

概述页最后生成，只能从已经通过门禁的分页面主旨句中选择最重要的3—5条，不得重新产生没有证据的新原因。

## 证据包格式

建议输出 `narrative_evidence.json`：

```json
{
  "run_id": "month-20260929-100000-ab12cd34",
  "report_month": "2026-08",
  "slides": [
    {
      "slide": 20,
      "topic": "车型级别",
      "anomaly": {
        "type": "reversal",
        "priority": 1,
        "fact_ids": ["P2-3.1:A0:yoy", "P2-3.1:C+:yoy", "history:2026-07:C+:yoy"]
      },
      "headline": "新车放量带动A0级同比转正，C+级优势终止",
      "body_claims": [
        {
          "claim": "A0级转正与多款新车放量同期发生",
          "fact_ids": ["P2-3.1:A0:yoy"],
          "evidence_ids": ["EV-001"],
          "certainty": "supported"
        }
      ]
    }
  ],
  "evidence": [
    {
      "id": "EV-001",
      "source_type": "new_car_plugin",
      "source_name": "新车数据底座",
      "url_or_record_id": "record-id",
      "published_at": "2026-08-15",
      "applicable_month": "2026-08",
      "entities": ["车型A"],
      "grade": "A",
      "summary": "车型A于目标月份进入交付爬坡",
      "retrieved_at": "2026-09-29T10:00:00+08:00"
    }
  ],
  "collection_batches": [
    {
      "batch_id": "evidence-new-car-001",
      "status": "completed",
      "evidence_ids": ["EV-001"],
      "attempts": 1
    }
  ]
}
```

证据包属于 `run_id`，保存后才能进入PPT更新阶段。PPT更新只读取该文件，不在写入过程中继续检索或改变观点。

提交分析版前运行：

```powershell
python scripts/validate_narrative_evidence.py narrative_evidence.json
```

校验器只验证最低结构与证据约束，不能替代业务专家复核。
