# PPT 更新与映射规范

仅在“数据源更新固定 PPT”模式下阅读。

## 数据更新滞后例外

目标月份已经确认时，完整读取但实际月份早于目标月的卡片允许作为 `delayed_allowed` 通过。按映射表记录对应页面及实际月份，保留整页原文字、图表、工作簿，不将旧值改名为目标月值。相关页不生成当月主旨句、不进入当月概述，质量记录列明 `retained_pages`。无法确认月份、缺失卡片、读取失败、晚于目标月的冲突及交叉校验错误仍阻断。该业务例外不豁免模板月份、图表口径及输出验收要求。

## 映射清单

映射应覆盖四类目标：

1. `chart_series`：图表页码、图表标识、系列名称、分类、数值来源、单位换算、数字格式。
2. `table_cells`：页码、表格标识、行列或键、数值来源、数字格式。
3. `text_fields`：日期、周期、标题、页脚等确定性文本。
4. `insight_text`：观点句依赖的指标及比较口径。

推荐 JSON 结构：

```json
{
  "dashboard": {
    "name": "月报测试页",
    "url": "https://example/page/id",
    "as_of": "2026-07"
  },
  "cards": [
    {
      "id": "monthly_sales_yoy",
      "title": "分车型类别-单月销量和同比",
      "rows": [],
      "row_count": 4,
      "column_count": 5
    }
  ],
  "targets": [
    {
      "kind": "chart_series",
      "slide": 1,
      "target": "单月销量/2026",
      "source_card": "monthly_sales_yoy",
      "source_field": "2026-07销量",
      "transform": "divide_by_10000",
      "format": "0.0000"
    }
  ],
  "zero_denominator_rule": "blank"
}
```

## 数据规则

- 销量单位换算应显式记录，例如“辆 ÷ 10000 = 万辆”。
- 百分比图表底层值优先使用小数比例，例如 `0.551`，显示格式设为 `0.0%`；不要用 `55.1` 再套百分比格式。
- 同比、环比统一按 `(本期-上期)/上期`。上期为零时不能计算普通增长率。
- 累计值必须确认起止月份。不得把“2025累计”自动解释为全年或同期累计，应以页面表头、筛选条件或用户确认的口径为准。
- 保留负号和空白。页面缺失值、真实零值和不可计算值需要分别处理。

## 模板一致性检查

本项目已确认的库存仅标题角色及全年结构参照规则见 [page-business-support.md](page-business-support.md)。第7/8/12/13/15页右图全年值及标签保持原样，第17页才是同期累计；不以统一同比规则更改业务结构参照。库存页不得新增正文或压缩图表。

逐项与原页比较：幻灯片尺寸、页数、母版和布局；标题与正文的边界框、字号、字重、颜色和行距；图表位置、尺寸、类型、系列顺序、配色和柱间距；坐标轴范围、轴线、刻度、网格线和单位；图例位置和顺序；数据标签格式、精度、位置与百分号；同比/环比圈、箭头和柱顶数值之间的间距；表格行高、列宽、底色、边框和文字对齐；Logo、页脚、来源和页码。

若新数据导致柱高变化，应移动标注，不应通过改变整个版式解决。标注应避开柱顶数值、图例、图框边界、其他标注和标题。

## 可编辑性检查

- 图表必须是 PowerPoint 原生图表，不是图片。
- 图表应包含有效的嵌入工作簿或完整的原生文字数据，且系列引用有效。
- 表格必须是原生表格或用户明确接受的可编辑形状组合。
- 打开“编辑数据”后，分类、系列名、数值、顺序和图上显示一致。
- 若重建工作簿，只能把完整、已验证的字面数据物化为新快照；不要声称保留了原始数据源公式或血缘。
