# 乘用车市场月度报告 - 底层数据需求文档

## 数据来源

所有数据来源: **中汽数据有限公司终端零售数据**
- 历史月均数据: 2012-2025年月均
- 库存数据: 中汽数据有限公司库存数据(不含进口)

### 数据表2: 新车增量贡献表

**用途**: Slide 4 (新品驱动)
**粒度**: 月度 + 车型级
**字段**:

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 月份 | 字符串 | 跨年12个月(当月+1月至当月) |
| 新车增量 | 整数(辆) | 当月新车贡献增量 |
| 新车增量贡献率 | 小数 | 新车销量/市场同比增量绝对值 |
| 新车数量 | 整数 | 当月销量>1000辆的新车数量 |
| 车均销量 | 数值(万辆) | 新车平均销量 |

**子表 - 典型新车月度销量**:
- 典型新车A: 上市后各月销量(辆)
- 典型新车B: 上市后各月销量(辆)
- 典型新车C: 上市后各月销量(辆)
- 各车型增量贡献度(百分比)

**定义说明**:
- 新车: 全新车型，跟踪周期为上市后12个月
- 增量贡献度 = 新车销量 / 乘用车市场同比增量绝对值
- 新车数量: 当月销量>1000辆的新车
- 车均销量: 销量>1000的新车的平均销量

## 数据一致性校验规则

在数据校验阶段，对照以下规则检查数据(详见 references/dimension_guide.md):

| 校验项 | 规则 | 容差 |
|--------|------|------|
| 份额加总 | 各类别当月份额之和 = 100% | ±0.1% |
| 累计值 | 累计值 = 1月至当月各月值之和 | 精确 |
| 同比计算 | 同比 = 当月值/去年同月值 - 1 | ±0.1% |
| 环比计算 | 环比 = 当月值/上月值 - 1 | ±0.1% |
| BEV+PHEV | BEV销量 + PHEV销量 = NEV总销量 | 精确 |
| 渗透率 | NEV销量/乘用车总销量 = 渗透率 | ±0.1% |
| 排名一致性 | 排名变化方向与实际排名变动一致 | 精确 |
| 图表-表格一致 | 同一指标在图表和表格中数值相同 | 精确 |
