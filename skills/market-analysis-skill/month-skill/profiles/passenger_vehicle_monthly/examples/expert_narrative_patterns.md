# 专家表达模式摘要

## 模式一：类别市场分化

先判断轿车、SUV、MPV 的同比方向和降幅变化，再把共同原因与类别特有原因分开：

- 共同原因：同期促销高基数、油价、政策或季节性。
- 轿车特有原因：小车政策敏感、A级传统车压力或主力产品增长乏力。
- SUV 特有原因：新品支撑、老产品下滑、头部车型新老切换。
- MPV 特有原因：核心车型换代等待、同期新品放量高基数。

## 模式二：总体判断后落到车型

不要先列四类销量。先说“同比降幅扩大/收窄、环比转正/转负”，再用代表车型证明哪些产品拉动、哪些产品拖累，最后说明是结构性趋势还是产品周期扰动。

## 模式三：原因层级

```text
市场结果
  -> 类别/级别结构
  -> 代表车型变化
  -> 产品/政策/价格/基数事件
  -> 对下月的影响
```

案例用于提炼方法，不应把某个月份的结论机械复制到新月份。
