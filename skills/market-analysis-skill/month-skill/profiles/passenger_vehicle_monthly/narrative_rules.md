# 月报市场深度分析写作规则

## 一、每页的咨询表达公式

每页正文按以下顺序组织，不能从数据罗列开始：

1. **总体判断**：用一句话概括本页市场是扩大、收缩、分化、切换还是企稳。
2. **代表车型**：从 TOP15 中选择 2-3 个真正解释市场变化的车型，写清同比、环比或排名方向。
3. **原因机制**：结合内部资料或外部权威来源，解释新品爬坡、老产品衰退、改款切换、同期基数、促销、油价、政策、供给或渠道因素。
4. **结构含义**：说明这类变化意味着份额迁移、竞争加剧、需求切换还是短期扰动。
5. **小结/观察点**：给出下一月应继续观察的车型、政策或供给变量。

推荐句式：

```text
[月份]，[市场总体表现]，主要受[机制1]和[机制2]影响；其中[车型A]与[车型B]分别体现[增长/下滑路径]，[结构变化或下月观察点]。
```

## 二、页面标题

标题必须是判断句或因果句，优先使用：

- `[核心机制]影响下，[市场结果]`
- `[增长来源]支撑，[下滑来源]拖累，[结构结果]`
- `[产品周期/政策/价格]驱动，[级别或类别]分化加剧`

禁止：

- “2026年6月车型类别销量走势”这类纯图名；
- “SUV表现最好、MPV表现最差”这类机械排名；
- 把多个百分比直接拼成标题。

## 三、代表车型选择

TOP15 是筛选池，不是结论。优先顺序：

1. 对市场绝对增量或减量贡献最大的车型；
2. 环比突变、排名明显升降或份额快速变化的车型；
3. 当月上市、换代、改款、停产或价格调整的车型；
4. 能代表该级别竞争格局变化的主力车型。

正文直接写车型名和变化，不出现“TOP15样本”“候选”“估算同比增减量”。每页通常不超过 3 个车型，避免把报告写成排行榜解说。

## 四、内部优先的证据链

| 层级 | 来源 | 用法 |
| --- | --- | --- |
| L1 | 内部终端销量、份额、排名 | 证明发生了什么 |
| L2 | 内部新车、价格、促销、政策、油价和历史月报 | 解释为什么发生 |
| L3 | 政府、协会、主机厂官方来源 | 补充可核验事件 |
| L4 | 专业行业媒体或数据库 | 补充产品和竞争线索 |
| L5 | 普通媒体和搜索摘要 | 只作为线索，不单独支撑强因果 |

强因果结论必须满足：

```text
内部销量变化成立 AND 事件来源可追溯 AND 事件时间与销量变化窗口一致
```

如果只满足一部分，写成“可能受……影响，仍需结合……核验”，或放入观察项。

## 五、五页分析重点

### 2.1 车型类别

- 先判断轿车、SUV、MPV的同比和环比分化。
- 再用各类别代表车型解释拖累或支撑。
- 原因优先考虑同期高基数、油电替代、产品切换和新品承接。

### 2.2 车型级别

- 识别 A00/A0/A/B/C+ 的份额迁移方向。
- 区分结构性变化与单一车型异常。
- 说明新品、价格带竞争或消费结构如何影响级别变化。

### 2.3 轿车级别

- 关注小型车政策敏感性、A级传统车压力、B/C+级产品更新。
- 代表车型要能连接价格、促销、能源路线或生命周期。

### 2.4 SUV级别

- 关注主流价格带、新品承接、老产品周期和竞品替代。
- 区分某一车型下滑与整个级别需求走弱。

### 2.5 MPV级别

- 关注商务/家用场景、核心车型换代窗口和供给变化。
- 主力车型数量较少，更要避免把单车波动直接解释为长期趋势。

## 六、数字和展示规范

- 销量按业务口径统一为辆或万辆，不在同一图表混用。
- 正增长写 `8.2%`，不写 `+8.2%`；负增长写 `-8.2%`。
- 份额变化使用百分点时写 `1.2个百分点` 或 `1.2pp`，方向由文字说明。
- 业务正文和 PPTX 不展示 `〔R1〕`、`〔E1〕` 等编号。
- 数据来源在报告末尾或页脚统一标注，不在每句话后重复。

## 七、输出前自问

1. 第一眼能否看出本页总体判断？
2. 车型是否真正解释本页结构变化？
3. 原因是否有来源，时间是否吻合？
4. 是否说明了“意味着什么”，而不是只说“发生了什么”？
5. 是否存在内部过程词、证据编号、正数加号或口径混用？
