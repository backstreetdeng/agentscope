# 月报数据契约

## 1. 当前兼容格式

当前运行时兼容按月份工作表组织的展示型交叉表。每个工作表至少包含五个分区：

- `车型类别`
- `车型级别`
- `轿车-级别`
- `SUV-级别`
- `MPV-级别`

各分区需要提供：标签、上年同期销量、当月销量、同比、环比、上年累计、本年累计、累计同比和份额期间。轿车、SUV、MPV 分区还需提供 TOP15：

```text
车型名称、当月销量、同比、环比、级别、份额、排名变化、累计销量
```

工作表名称建议使用 `1月`、`2月` 等；报告月份由用户问题和工作表共同确定。

## 2. 口径要求

- 明确终端零售、批发、上险或交付，不允许混用。
- 销量字段明确单位。当前运行时能识别辆/万辆，但同一工作簿应统一。
- 同比、环比和份额使用小数或百分比时保持一致。
- 正值不需要加号；负值必须保留负号。
- 所有数据附带版本日期、数据提供部门和修订说明。

## 3. 推荐的生产数据模型

为便于同事新增品牌、区域、能源、价格带等页面，长期建议从展示型交叉表升级为以下规范表：

### fact_vehicle_monthly

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| period | YYYY-MM | 统计月份 |
| scope | text | 零售/批发/上险/交付 |
| model_id | text | 稳定车型编码 |
| model_name | text | 车型名称 |
| brand | text | 品牌 |
| manufacturer | text | 企业 |
| category | text | 轿车/SUV/MPV/交叉型 |
| level | text | A00/A0/A/B/C+ |
| energy_type | text | 燃油/纯电/插混/增程等 |
| price_band | text | 价格带 |
| region | text | 全国或区域 |
| sales | integer | 销量 |
| yoy | decimal | 同比 |
| mom | decimal | 环比 |
| share | decimal | 份额 |
| rank | integer | 当月排名 |
| cumulative_sales | integer | 累计销量 |

### dim_model_lifecycle

记录上市、换代、改款、停产、新老款切换和交付爬坡时间。

### fact_market_events

记录政策、油价、价格调整、促销、渠道和供应事件，至少包含事件日期、来源、适用车型/市场、可信等级和原文链接。

### report_case_library

保存正式月报页面、对应数据快照、专家标题、专家分析段落、证据与验收结果，用于少样本检索和回归评估。

## 4. 新页面的最小数据定义

新增页面前必须写清：

1. 分析对象；
2. 时间粒度；
3. 统计口径；
4. 维度与指标；
5. 排序/筛选规则；
6. 可解释事件；
7. 允许缺失和阻断条件；
8. 页面图表与文字字段映射。
