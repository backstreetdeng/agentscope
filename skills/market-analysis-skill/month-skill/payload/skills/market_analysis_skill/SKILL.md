# 中国乘用车市场月报分析

本 Skill 的目标不是把销量表改写成文字，而是将业务专家的固定分析路径稳定地落地为：
数据可追溯、结论有边界、缺口不编造的市场报告。

## 触发与输入

- 显式模式：`analysis_type=market_monthly_report`。
- 自动模式：问题含“月报、月度报告、市场走势、车型类别、车型级别、细分市场结构、TOP车型、销量结构”等关键词。
- 支持 `.xlsx`；默认优先读取 `MARKET_ANALYSIS_DATA_PATH`，其次读取 `model_config/config.json` 中的默认数据集。
- 当前业务验数样本是展示型交叉表。它可支撑类别/级别、同比/环比、结构变化的分析，但不能替代车型、品牌、区域或用户明细库。

## 执行流程

1. 读取工作表、统计周期、车型类别/级别和同比环比指标。
2. 执行输入数据门禁：文件可读、统计周期、结构维度、趋势指标、车型品牌竞争数据、口径边界。
3. 把已验证数据摘要与报告结构注入市场战略 Agent。
4. 仅对数据集已覆盖的字段下确定量结论；政策、新品、油价、竞品原因需要实时检索证据。
5. 模型返回后检查章节、来源、展望确定性和数据缺口披露。

## 报告结构

使用如下章节，数据不足时保留章节并说明“当前数据未提供”：

```text
# [年份]年[月份]中国乘用车市场分析报告
## 核心数据速览
## 01 当月乘用车市场走势解读
## 02 当月乘用车市场结构特征分析
### 2.1 车型类别
### 2.2 车型级别
### 2.3 轿车级别分析
### 2.4 SUV级别分析
### 2.5 MPV级别分析
## 03 下月乘用车市场展望
## 数据来源与数据缺口
```

每个层级要先呈现事实，再解释“为什么”和“意味着什么”；趋势展望标注高/中/低确定性及风险变量。

## 禁止事项

- 不把展示型验数表解释为完整车型、品牌或区域明细。
- 不在缺少车型销量表时虚构 TOP15、排名变化、CR5 或品牌集中度。
- 不把未经工具检索证实的政策、新品、油价、竞品原因写成确定事实。
- 不混用批发、零售、上险、交付等口径；无法确认时要求补充说明。
