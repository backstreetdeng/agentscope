# 常见问题排查

## Skill 未触发

- 显式传入 `analysis_type=market_monthly_report`。
- 检查 `skills.market_analysis.enabled` 和 `auto_trigger`。
- 普通机会市场问题本来就不应触发月报长模板。

## 找不到数据集

优先级为：调用参数、`MARKET_ANALYSIS_DATA_PATH`、模型配置、安装包演示数据。确认文件为未加密 `.xlsx`，路径使用绝对路径或相对宿主项目根目录。

## 工作表选错

在问题中明确年份月份，或传入 `sheet_name="6月"`。工作表名不要混入不可见空格。

## TOP15 没有进入分析

检查轿车、SUV、MPV 分区是否包含完整字段，销量单位是否一致，以及车型名称、同比和环比是否可解析。TOP15 只负责选代表车型，真正原因还需要事件证据。

## 市场分析仍像数据罗列

依次检查：

1. `driver-select` 是否选出了代表车型；
2. 内部事件资料是否包含车型、日期和来源；
3. Agent Reach 是否返回了可追溯来源；
4. 模型输出是否覆盖“总体判断-车型-机制-小结”；
5. 输出门禁是否把浅层分析判为风险。

## MiniMax 未返回最终正文

- 检查宿主 `reasoning_split` 配置；
- 检查是否只返回 `<think>` 内容；
- 使用宿主工程已有的无 thinking 重试机制；
- 不把未闭合推理文本直接显示给用户。

## PPTX 页数或内容不对

- 默认母版必须至少 5 页。
- Markdown 必须有 2.1 至 2.5 对应章节。
- 新增页面不能只改提示词；必须同时扩展模板、解析器和渲染 handler。

## 图表重叠、标签重复或文字溢出

- 检查模板历史标签是否被清理；
- 检查图表分类轴和新增覆盖标签是否同时存在；
- 使用 PowerPoint 或 LibreOffice 渲染后做视觉检查；
- 将问题固化为回归测试，不要只手工修一次文件。

## Agent Reach 不可用

安装包的适配器依赖 `mcporter` 和可用的 Exa MCP 路由。不可用时将 `external_evidence.enabled` 设为 `false`；报告可以继续使用内部资料，但不得虚构外部原因。
