# 安装包分享检查清单

在复制到同事电脑、上传远程仓库或发送供应商前逐项确认：

- [ ] 不包含 `.env`、API Key、Token、账号或内部 URL 凭证。
- [ ] 演示 Excel 已确认可在目标范围内共享。
- [ ] PPTX 母版和字体、Logo、图片拥有共享权限。
- [ ] 专家月报案例未包含未公开经营数据。
- [ ] 用户访谈、音频、手机号、VIN 等个人数据未进入包。
- [ ] 研究证据只保留公开 URL 或获准共享的内部文档索引。
- [ ] ZIP 文件名、版本和 SHA256 已记录。
- [ ] 远程仓库可见性符合业务资料保密等级。

本包默认是内部预览版，不等于自动获得外部发布许可。
