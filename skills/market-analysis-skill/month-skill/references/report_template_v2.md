# 乘用车市场月度报告 - 报告模板规范

## 概述

本文档定义乘用车月度报告的标准化格式规范，包括标题命名规则、分析文本撰写规范、表格格式标准、要点标记法、分析深度指导等。在撰写或审核分析文本时加载此文件。

### 标题撰写要点
- 核心结论必须是**具体的数据支撑的判断**，不是泛泛描述
- 好的标题: "SUV份额持续扩大，轿车同比下降明显" — 有方向、有对比
- 差的标题: "各车型类别表现分化" — 没有具体方向
- 标题长度控制在20-30字以内

## 二、分析文本撰写规范

### 段落结构

每页分析文本通常包含2段:

**第1段: 当月分析**(100-200字)
```
{当月销量}万辆，同比{增/降}{百分比}，环比{增/降}{百分比}。
{核心变化描述}。
{驱动因素分析：政策/产品/季节/竞争等}。
{结构性亮点或隐忧}。
```

**第2段: 累计分析**(50-100字)
```
1-{当月}月累计{销量}万辆，同比{增/降}{百分比}，{增速较去年同期变化}。
{累计趋势判断}。
```

### 撰写示例(以Slide 3零售量为例)

**好的分析文本**:
> {当月}月乘用车终端零售[销量]万辆，同比[增幅]，环比[增幅]。剔除季节性因素后，降幅较上月收窄[幅度]个百分点。新能源车型渗透率达到[百分比]，较去年同期提升[幅度]个百分点，成为支撑市场的重要力量。传统燃油车同比[增幅]，拖累整体市场表现。
>
> 1-{当月}月累计零售[销量]万辆，同比[增幅]，降幅较上期收窄[幅度]个百分点，市场呈现温和复苏态势。

**差的分析文本**(仅复述数据):
> {当月}月乘用车终端零售[销量]万辆，同比[增幅]，环比[增幅]。1-{当月}月累计[销量]万辆，同比[增幅]。

### ◼ 要点标记法

在部分页面(如Slide 4新品驱动)的分析文本中，使用 `◼` 标记驱动因素要点:
```
◼ 新车增量贡献率达到[百分比]，环比提升[幅度]个百分点
◼ [典型新车]上市首月销量突破[销量]辆，贡献最大增量
◼ 纯电新品贡献度高于插混，反映消费偏好转向
```

## 四、分析深度指导

### 三层分析深度要求

**第一层: 数据陈述(必须)**
- 当月销量、同比、环比的准确数据
- 累计数据及同比
- 份额及变化

**第二层: 结构性判断(必须)**
- 份额迁移方向(谁在扩大、谁在萎缩)
- 趋势拐点(增速由正转负、降幅收窄等)
- 排名变化分析
- 结构性分化(如"新能源增长但传统车拖累整体")

**第三层: 驱动因素(应当)**
- 政策因素(补贴退坡、以旧换新等)
- 产品周期(新车上市、车型换代)
- 季节性因素(春节、车展、季末冲量)
- 竞争格局(价格战、新进入者)
- 消费趋势(消费升级/降级、偏好转变)

### 禁止的分析模式

**禁止仅复述数据**:
- ❌ "轿车销量45.2万辆，同比下降12.3%。SUV销量78.5万辆，同比下降10.5%。"
- ✅ "轿车同比下降12.3%，降幅大于SUV(-10.5%)，主要受A级轿车需求萎缩影响。SUV份额扩大至50.2%，连续6个月保持份额提升趋势。"

**禁止脱离数据的空洞判断**:
- ❌ "市场竞争激烈，各企业表现分化。"
- ✅ "比亚迪以12.5%的份额稳居榜首，吉利(+1.2pp)和长安(+0.8pp)份额提升，而一汽大众(-1.5pp)和上汽大众(-1.2pp)份额持续下滑，自主品牌包揽前三的趋势进一步巩固。"

## 六、报告完整性检查表

生成报告后，逐项检查:

### 数据完整性(7项)
- [ ] 1. 所有19张数据表已加载且字段完整
- [ ] 2. 当月数据与同比/环比计算自洽
- [ ] 3. 份额加总等于100%(±0.1%误差)
- [ ] 4. 累计值 = 各月值之和
- [ ] 5. 排名变化与实际排名一致
- [ ] 6. 图表数据与表格数据一致
- [ ] 7. AutoShape标注(椭圆/矩形)与数据一致

### 内容完整性(6项)
- [ ] 8. 所有内容页标题已更新(含月份和核心结论)
- [ ] 9. 所有分析文本框已填充(非空、非模板文字)
- [ ] 10. 分析文本包含结构性判断(非仅数据复述)
- [ ] 11. 标题结论与正文分析逻辑一致
- [ ] 12. 封面日期正确(报告月份的下一个月)
- [ ] 13. 数据来源标注完整

### 格式完整性(3项)
- [ ] 14. 所有图表数据已更新(无残留旧数据)
- [ ] 15. 所有表格已更新(无空行、无占位符)
- [ ] 16. AutoShape标注全部更新(椭圆增速+矩形标签)
