# 中国乘用车市场分析

## 概述

本技能用于将原始乘用车终端零售数据转化为标准化的市场分析报告。报告遵循中汽数据行业分析规范，包含市场走势解读、结构特征分析和趋势展望三大部分。

## 分析工作流

生成乘用车市场分析报告包含以下步骤：

1. **数据梳理** — 整理销量数据表格，确认分析维度
2. **市场走势解读** — 整体市场表现、同比环比、累计趋势
3. **结构特征分析** — 车型类别 -> 车型级别 -> 细分市场的逐层下钻，每层含小结
4. **趋势展望** — 基于当月数据推演下月走势，含确定性判断
5. **报告整合** — 按标准格式组装输出，含核心数据速览和完整性检查

## 第一步：数据梳理

### 确认数据维度

原始数据应至少包含以下维度中的一个或多个：

| 维度 | 字段 | 说明 |
|------|------|------|
| 时间 | 月份、年份、累计标识 | 区分单月(单)和累计(累)数据 |
| 车型类别 | 轿车、SUV、MPV、交叉型 | 大类划分 |
| 车型级别 | A00、A0、A、B、C+ | 尺寸/定位分级 |
| 销量 | 万辆/辆 | 当月或累计销量 |
| 同比 | 百分比 | 与去年同期对比 |
| 环比 | 百分比 | 与上月对比 |
| 份额 | 百分比 | 该细分市场占总市场比例 |
| 车型明细 | 车型名称、销量、同比、环比、级别、份额 | TOP排名用 |

### 数据完整性检查

- 如有缺失维度，在报告中注明数据来源限制
- 优先保证**整体市场总量**和**车型类别**数据完整
- TOP车型排名数据若缺失，可省略该部分

## 第二步：市场走势解读

### 核心指标

解读当月市场整体表现时，必须覆盖以下指标：

1. **当月销量**（万辆）及同比/环比变化
2. **累计销量**（万辆）及同比变化
3. **市场总体趋势定性**：增长/下滑/企稳，并给出核心驱动因素

### 核心数据速览摘要表

在详细分析之前，先输出一个核心数据速览摘要表，便于读者快速把握全貌：

| 指标 | 当月值 | 同比 | 环比 | 累计值 | 累计同比 |
|------|--------|------|------|--------|----------|
| 乘用车总量（万辆） | [x.x] | [+/-x.x%] | [+/-x.x%] | [x.x] | [+/-x.x%] |
| 轿车（万辆/份额） | [x.x]/[x.x%] | [+/-x.x%] | [+/-x.x%] | [x.x]/[x.x%] | [+/-x.x%] |
| SUV（万辆/份额） | [x.x]/[x.x%] | [+/-x.x%] | [+/-x.x%] | [x.x]/[x.x%] | [+/-x.x%] |
| MPV（万辆/份额） | [x.x]/[x.x%] | [+/-x.x%] | [+/-x.x%] | [x.x]/[x.x%] | [+/-x.x%] |
| 新能源渗透率 | [x.x%] | [+/-x.xpp] | [+/-x.xpp] | [x.x%] | [+/-x.xpp] |

*注：pp = 百分点。此表用于读者快速把握核心数据，后续各章节展开详细分析。*

### 分析要点格式

以要点形式列出，每条以 `◼` 开头，格式为：

```
◼ [月份]，[市场总体表现描述]，主要受[因素1]、[因素2]影响。[补充说明特殊事件或结构性变化]。
```

示例：
```
◼ 4月，轿车和SUV市场同比均呈两位数负增长，除去年同期一口价促销拉高基数以及今年油价持续高位传统车表现不佳影响外，前者受政策影响下宏光MINI、海鸥等小车销量下滑拖累，后者虽有新产品支撑但理想L6、宋PLUS等老产品仍销量下滑显著。
```

### 注意事项

- 同比变化需说明基数效应（去年同期是否有促销/政策等特殊因素）
- 环比变化需考虑季节性（春节、国庆等节假日前后波动）
- 油价、政策、新品上市是常见的核心影响因子

## 第三步：结构特征分析（核心）

### 分析层级

按自上而下的层级逐层分析：

```
第一层：车型类别（轿车 / SUV / MPV / 交叉型乘用车）
    |
第二层：车型级别（A00 / A0 / A / B / C+）
    |
第三层：细分市场（轿车分级别 / SUV分级别 / MPV分级别）
    |
第四层：TOP车型排名
```

**每个层级分析完毕后，必须撰写一段200-300字的小结**（见3.4节）。

### 分析深度要求

#### 超越数据复述
每条分析要点不应仅重复表格中的数字，而应回答"为什么"和"意味着什么"：

| 层级 | 不要这样写 | 要这样写 |
|------|-----------|----------|
| 类别 | "SUV销量同比增长5.2%" | "SUV市场同比转正（+5.2%），主要受理想L6、问界M7等新车放量驱动，份额较上月提升1.3pp至48.6%，创历史新高" |
| 级别 | "A00销量1.2万辆" | "A00市场持续萎缩（1.2万辆，同比-35%），补贴政策退坡后代步需求向A0级上移，市场结构从哑铃型向纺锤型转变" |
| 细分 | "Model 3销量1.5万辆" | "Model 3国内交付1.5万辆（环比-12%），受出口订单攀升分流影响，国内份额从8.2%降至7.1%" |

#### 结构性模式识别
在分析中寻找并明确表述以下结构性模式：
- **格局演变**：市场集中度变化（CR3/CR5/CR10升降）
- **结构转型**：级别间份额迁移方向（如消费升级/降级、小车市场萎缩）
- **竞争态势**：新能源对传统燃油的替代节奏、自主vs合资份额变化
- **异常信号**：与历史规律偏离的数据点（如某级别逆势增长、某车型排名突变）

#### 多维度交叉分析
鼓励在要点中进行跨维度关联：
- 销量变化 + 份额变化 + 排名变化 = 综合判断市场地位
- 同比 + 环比 + 季节性 = 区分趋势性变化与短期波动
- 个体车型表现 + 级别整体表现 = 识别是结构性因素还是个体因素

### 3.1 车型类别分析

对每个类别（轿车、SUV、MPV、交叉型）分别说明：

- 当月销量、同比、环比
- 份额及份额变化
- 表现好/差的核心原因

#### 标准输出表格格式

**月销量表：**

| | 轿车 | SUV | MPV | 交叉型乘用车 |
|---|------|-----|-----|-------------|
| 2025年[月] | [销量] | [销量] | [销量] | [销量] |
| 2026年[月] | [销量] | [销量] | [销量] | [销量] |
| 同比 | [增幅] | [增幅] | [增幅] | [增幅] |
| 环比 | [增幅] | [增幅] | [增幅] | [增幅] |

**份额走势表：**

| | 轿车 | SUV | MPV | 交叉型乘用车 |
|---|------|-----|-----|-------------|
| [上月] | [份额] | [份额] | [份额] | [份额] |
| [当月] | [份额] | [份额] | [份额] | [份额] |
| 2025全年 | [份额] | [份额] | [份额] | [份额] |
| 2026累计 | [份额] | [份额] | [份额] | [份额] |

**当月/累计份额变化：** 分别列出当月份额较上月变化和累计份额较2025全年变化。

#### 分析要点模板

```
◼ [月份]，[类别A]和[类别B]市场同比均呈[正/负]增长，主要受[因素1]、[因素2]影响。
  [类别C]市场同比降幅[扩大/收窄]，主要受[具体原因]影响。
```

### 3.2 车型级别分析

对各级别（A00、A0、A、B、C+）进行分析：

- 当月销量、同比、环比
- 份额走势
- 各级别表现差异的驱动因素

#### 分析重点

| 级别 | 典型关注点 |
|------|-----------|
| A00 | 政策影响（如补贴退坡）、代步需求变化 |
| A0 | 新品放量、降价促销效果 |
| A | 传统车基盘、油价敏感性 |
| B | 主力市场竞争、新能源渗透率 |
| C+ | 高端新品拉动、消费升级/降级 |

### 3.3 细分市场分析（轿车/SUV/MPV分级别）

对每个细分市场（如轿车分级别、SUV分级别、MPV分级别），分别输出：

#### 销量数据表格

包含：当月各级别销量、同比、环比、份额

#### TOP15车型排名表

| 车型 | 销量(万辆) | 同比 | 环比 | 级别 | 份额 | 排名变化 | 累计排名 |
|------|-----------|------|------|------|------|----------|----------|
| [车型名] | [销量] | [同比] | [环比] | [级别] | [份额] | [较上月变化] | [累计排名] |

**填色规则**：传统车型用蓝色标记，新能源车型用绿色标记。

#### TOP车型点评要点

- 新车上市：标注上市时间，说明贡献增量
- 出口分流：说明国内交付受出口订单影响（如Model 3）
- 老款下滑：说明产品生命周期末期表现
- 促销效果：说明降价/优惠对销量的拉动

#### 品牌集中度分析表

对每个细分市场，补充品牌层面的集中度分析：

| 品牌 | 当月销量（万辆） | 份额 | 较上月变化 | 主力贡献车型 | 同比变化 |
|------|-----------------|------|-----------|-------------|----------|
| [品牌1] | [x.x] | [x.x%] | [+/-x.xpp] | [车型1, 车型2] | [+/-x.x%] |
| [品牌2] | [x.x] | [x.x%] | [+/-x.xpp] | [车型1] | [+/-x.x%] |
| TOP5合计 | [x.x] | [x.x%] | [+/-x.xpp] | - | - |
| CR5 | [x.x%] | - | [+/-x.xpp] | - | - |

**集中度趋势判断**：CR5同比/环比变化说明品牌集中度在提升还是分散，结合具体品牌升降给出解读。

#### 分析要点模板

```
◼ [月份]，[级别A]市场同比[增幅描述]，主要受[车型1]、[车型2]等[新车放量/降价促销/出口分流]影响。
  [级别B]市场同比降幅[扩大/收窄]，主要受[具体因素]拖累。[级别C]市场[特殊表现说明]。
```

### 3.4 结构特征小结

**每个层级分析结束后，必须撰写一段200-300字的小结**，包含：

1. **核心发现**：该层级最显著的1-2个结构性特征
2. **趋势判断**：用定性表述概括格局变化（如"市场结构从哑铃型向纺锤型转变"、"品牌集中度持续提升"）
3. **关键对比**：与上月/去年同期最显著的差异点

小结应放在该层级数据表格和要点之后、下一层级之前。

## 第四步：趋势展望

### 4.1 趋势展望表

基于当月数据分析，对下月/下季度市场走势进行预判，使用结构化表格：

| 展望维度 | 预判结论 | 确定性 | 核心论据 |
|----------|----------|--------|----------|
| 总量走势 | [增长/下滑/企稳，预计销量X万辆] | [高/中/低] | [论据1-2条] |
| 轿车市场 | [预判] | [高/中/低] | [论据] |
| SUV市场 | [预判] | [高/中/低] | [论据] |
| MPV市场 | [预判] | [高/中/低] | [论据] |
| 关键变量 | [新品/政策/油价等] | - | [具体影响路径] |

**确定性定义**：
- **高**：历史规律明确支撑，或已知的确定性事件（如已发布的新品上市时间表）
- **中**：基于当前趋势线性外推，但存在变量不确定性
- **低**：多重变量交织，难以形成明确方向判断

### 4.2 分析要点格式

```
## 03 下月乘用车市场展望

◼ 预计[下月]乘用车市场[判断]，主要基于：
  - [支撑因素1]
  - [支撑因素2]
  - [风险因素]
```

## 质量检查清单

### A. 数据一致性（必须全部通过）
- [ ] 表格中引用的关键数据（销量、份额、同比）与正文分析要点中的数字完全一致
- [ ] 文中提到的车型数量（如"TOP3""共5款"）与实际表格行数一致
- [ ] 各细分市场份额加总为100%（允许+/-0.5%四舍五入误差）
- [ ] TOP车型销量之和与所属细分市场的总销量逻辑一致（TOP10合计 <= 细分市场总量）
- [ ] 同比/环比方向正确（正增长/负增长符号无误）
- [ ] 排名变化计算正确（本月排名 - 上月排名 = 变化值）

### B. 格式规范
- [ ] 所有分析要点以 `◼` 开头
- [ ] 数据来源已标注（报告末尾统一标注即可）
- [ ] TOP15表中传统/新能源车型已区分（蓝色/绿色标注说明）
- [ ] 表格列对齐，数值小数位数统一

### C. 分析深度
- [ ] 每个分析层级（类别->级别->细分）有数据支撑的具体解读，而非仅复述数字
- [ ] 每个层级有小结段落
- [ ] 趋势展望部分包含确定性判断（高/中/低）及支撑论据
- [ ] 至少包含一个品牌集中度分析表
