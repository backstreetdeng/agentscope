# 战略 So What 规则

## 1. 结构

每条 So What：

```json
{
  "finding": "……（对象 + 方向 + 幅度/机制）",
  "type": "opportunity | threat",
  "confidence": "high | medium | low",
  "evidence_receipt_ids": ["…"],
  "horizon": "short_term(1-3月) | mid_term(3-12月)"
}
```

## 2. 规则

1. **推断与事实分离**：事实进矩阵；So What 是基于矩阵的判断，不引入矩阵外未取证的事实。
2. **证据锚定**：每条必须引用 `evidence_receipt_ids`；无证据的判断不输出。
3. **置信度标准**：
   - `high`：多源事实直接支持，无需推演
   - `medium`：单源事实或需一步推演
   - `low`：趋势外推或信号弱（必须说明依据）
4. **禁空话**：没有对象、方向、幅度的结论不合格（"竞争激烈""前景广阔"均不合格）。
5. **范围边界**：Phase 1 不做 L3 级五力、财务、估值推演；So What 聚焦对标差异的机会/威胁判断。
6. **数量约束**：L2 任务 3–6 条，宁缺毋滥；每条独立可行动。

## 3. 示例（格式参考，非真实结论）

- 合格："目标车型以 14.99 万限时价将激光雷达辅助驾驶带入 15 万级，较竞品 A 同档配置低约 1.5 万，短期对该价格带智驾平权形成直接压力（threat, medium, 短期）"
- 不合格："市场竞争日趋激烈，需加强产品力"（无对象、无方向、无幅度、无证据）
