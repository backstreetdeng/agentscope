# 字段级交叉校验规则

竞品对标 Skill 的证据纪律细则。SKILL.md 红线规则的展开，验收器（`scripts/validate_matrix.py`）的规则来源。

## 1. P0 锚定规则（硬参数）

| 字段 | 锚（miit.declaration） | 规则 |
|---|---|---|
| 纯电续航 | `ev_range_km` | 申报值为矩阵唯一取值；厂商 CLTC 宣传值仅可作 note 佐证并标注"宣传口径" |
| 整备质量 | `curb_weight_kg` | 同上 |
| 能耗 | `energy_cons` + `energy_cons_unit` | kWh/100km 与 L/100km 不可比，必须带单位分列 |
| 电池能量 | `battery_kwh` | 同上 |

未在申报库中的车型（未申报/进口等）：该维度标 `insufficient` 并注明"无申报记录"，**不得**用媒体值顶替。

## 2. 价格阶梯规则

四级分列存储，禁止合并为单一"价格"：

| 级 | 含义 | 典型来源 |
|---|---|---|
| 指导价 | 厂商官方指导价（MSRP） | 官网 / 权威媒体 |
| 先享价 | 上市先享指导价 | 官网 |
| 限时价 | 限时焕新/优惠价（带有效期） | 官方发布 / 权威媒体 |
| 经销商价 | 终端参考价（区域行情） | 经销商报价平台（P2，带区域标注） |

- 每级必须带 `as_of` 时间戳与 `receipt_id`。
- 预售价 ≠ 上市价，分别记录（实测案例：某车型预售 19.98 万 → 指导 18.98 万 → 先享 17.98 万 → 限时 16.98 万，四级并存）。

## 3. 冲突三型分治

| 型 | 判定特征 | 处理规则 |
|---|---|---|
| 口径冲突 | CLTC vs 申报工况；批发 vs 零售；不同统计机构 | 双值并列 + 口径标注，**不取舍**；无法判定哪方口径时标 `disputed` |
| 时效冲突 | 公告批次数据 vs 当前市场数据 | 以 `as_of` 分列呈现；数据龄 >6 个月时提示业务复核 |
| 立场冲突 | 官方宣传 vs 评测实测 | 双边呈现 + 来源等级标注；实测值注明测试条件 |

## 4. 单元格标注状态

| 状态 | 判定 |
|---|---|
| `confirmed` | ≥3 个独立来源一致 |
| `majority` | 多数来源一致但不足 3 个独立源 |
| `disputed` | 冲突未消解（必须双边呈现） |
| `single_source` | 仅 1 个来源 |
| `insufficient` | 数据存在但质量不足（如无申报记录） |
| `na` | 该维度不适用或未采集 |

## 5. 独立性判定

- 同一媒体集团 / 同一转载链 / 互相引用的来源，**不算独立**。
- 官方发布 + 权威媒体转述 = 实质 1 个独立来源（转述方需可回溯到首发）。
